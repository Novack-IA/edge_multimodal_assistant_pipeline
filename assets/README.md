# assets/

Coloque aqui a amostra de voz de referência para clonagem do XTTS-v2
(`tts.speaker_wav` em `config.yaml`, default `assets/reference_voice.wav`).
Um ou mais arquivos `.wav` de referência são aceitos (docs/07 §3). Arquivos
de áudio não são versionados (ver `.gitignore`) — cada device/voz é local.
